# HTTP Methods

## GET

```bash
curl -X GET https://example.com
```

Retrieve data.

---

## POST

```bash
curl -X POST https://example.com/login
```

Send data.

---

## PUT

```bash
curl -X PUT https://example.com/api/user
```

Update resources.

---

## DELETE

```bash
curl -X DELETE https://example.com/api/user
```

Delete resources.

---

## HEAD

```bash
curl -I https://example.com
```

Retrieve headers only.

---

## OPTIONS

```bash
curl -X OPTIONS https://example.com
```

Show allowed methods.
