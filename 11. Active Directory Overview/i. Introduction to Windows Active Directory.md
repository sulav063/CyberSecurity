# Introduction to Windows Active Directory

## Overview

Active Directory (AD) is Microsoft's centralized directory service used for managing users, computers, groups, permissions, and resources inside an organization.

It enables administrators to manage thousands of systems from a single location.

Active Directory is heavily used in enterprise environments and is one of the primary targets during internal penetration tests.

---

## Why Active Directory Exists

Without Active Directory, administrators would need to configure:

- Users individually
- Password policies separately
- Permissions manually
- Each computer independently

Active Directory provides centralized management.

---

## Features of Active Directory

- Centralized authentication
- Authorization and access control
- Group policy management
- Resource sharing
- User management
- Domain administration

---

## Authentication Protocols

Active Directory mainly uses:

### Kerberos

Default authentication protocol used in modern domains.

### NTLM

Legacy authentication protocol.

---

## Active Directory Objects

Examples:

- Users
- Computers
- Groups
- Printers
- Shared folders

---

## Benefits of Active Directory

- Simplifies administration
- Improves security
- Centralized management
- Easier policy enforcement

---

## Importance in Cybersecurity

Most corporate penetration tests involve Active Directory.

Attackers often target:

- Domain Controllers
- Kerberos
- User accounts
- Misconfigurations

---

## Key Takeaways

- Active Directory is Microsoft's directory service.
- Used in enterprise networks.
- Centralizes authentication and authorization.
- Common target during internal penetration testing.
