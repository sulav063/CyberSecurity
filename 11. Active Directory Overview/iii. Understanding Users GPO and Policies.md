# Understanding Users, GPO and Policies

## Users

Users represent individual accounts inside Active Directory.

Examples:

- Administrator
- John
- HRUser

---

## Groups

Groups allow administrators to assign permissions efficiently.

Examples:

- Domain Users
- Domain Admins
- Remote Desktop Users

---

## Password Policies

Organizations can enforce:

- Minimum password length
- Password complexity
- Account lockout policies

---

## Group Policy Objects (GPO)

Group Policies are used to configure multiple systems automatically.

Administrators can control:

- Password policies
- Desktop settings
- Software installation
- Security configurations

---

## Examples of GPO Usage

- Disable USB devices
- Enforce screen lock
- Disable Control Panel
- Configure Windows Defender

---

## Policy Hierarchy

Policies can apply to:

1. Site
2. Domain
3. Organizational Unit

---

## Why GPO Is Important

GPO enables:

- Centralized management
- Security enforcement
- Standardized configurations

---

## Importance in Cybersecurity

Misconfigured policies may lead to:

- Privilege escalation
- Weak passwords
- Excessive permissions

---

## Key Takeaways

- GPO controls multiple computers.
- Password policies improve security.
- Groups simplify access management.
