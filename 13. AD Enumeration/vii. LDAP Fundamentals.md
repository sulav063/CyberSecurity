
## Overview

LDAP (Lightweight Directory Access Protocol) is a protocol used to communicate with directory services such as Active Directory.

LDAP allows applications and administrators to:

- Search users
- Search groups
- Search computers
- Manage directory objects

---

# LDAP Structure

```text
Directory

│

├── Users

├── Groups

├── Computers

└── Organizational Units
```

---

# Common Uses

- User Authentication
- Directory Search
- Object Management
- Centralized Administration

---

# LDAP vs Active Directory

| LDAP | Active Directory |
|-------|------------------|
| Protocol | Directory Service |
| Communication | Database |

---
# Example Commands

These commands display networking information related to directory services.

---

## Display DNS Configuration

```bash
ipconfig /all
```

Displays configured DNS servers and adapter information.

---

## Display Hostname

```bash
hostname
```

Displays the current computer name.

---

## Test Network Connectivity

```bash
ping google.com
```

Tests basic network connectivity.
